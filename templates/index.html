MechAI is a full-featured lean manufacturing analysis tool built for real factory floor data. Load any assembly line project, run a complete 11-section analysis — from ASME Flow Process Charts to Kanban card generation — and export a professional PDF report.

INTERPRETATION EVALUATION PREDICTION
What MechAI Does — 12 Analysis Modules Full Report
# Module What it calculates / generates
01 AS-IS Summary Standard time, normal time, takt time, bottleneck station, line efficiency %, balance efficiency %, NVA steps, units per shift — from observed time data.
02 Flow Process Chart ASME standard symbols (Operation O, Transport →, Inspection □, Delay D, Storage ▽) with zigzag connecting line, step count, total distance, and lean recommendations.
03 Line Balance Chart Bar chart of cycle time per workstation vs takt time line. Bottleneck station highlighted separately. Idle time shown per station.
04 Plant Layout Generator 5 layout types: AS-IS (current with backtracking arrows), U-Shape (zero backtracking), Process (by function), Mixed, Static (fixed product). Interactive Plotly diagrams.
05 Efficiency Comparison Current vs optimised across 4 separate charts: cycle time per station, KPI comparison (units/shift, line eff, balance eff, NVA steps), VA vs NVA time split, and improvement gain summary.
06 SOP Generator Standard Operating Procedure card for every workstation — document number, who/what/where/when, step-by-step procedure, safety requirements, and quality checks.
07 Cost Calculator Converts cycle time to ₹ cost. Editable wage/worker/overhead inputs. Outputs: current cost/unit, optimised cost/unit, savings per unit / per shift / per day / per month.
08 Daily Production Report Editable shift-level DPR table: cooler type, qty planned, qty produced, dispatch time, end-of-day inventory, remarks. Fillable per shift.
09 Shop Production Schedule Gantt consignment chart across Sheet Metal, Powder Coating, and Assembly shops for one full shift (480 min). Task blocks with start/end times and handover points.
10 ABC Inventory Analysis A-B-C classification by annual value. Pareto bar chart + cumulative % line + donut chart. Table with unit cost, annual usage, annual value, lead time, replenishment strategy per item.
11 Kanban Cards Production Kanban cards for all A and B items — Part No., description, qty per card, lead time, reorder point, max stock, supplier, bin location, running status, due date.
12 ML Predictions AI 4 scikit-learn regression models trained on station data — Bottleneck Forecast (which station breaches takt as output demand rises), Output Forecast (units/shift vs operator count), Idle Time Prediction (cumulative idle per takt range), Stockout Risk (days-to-stockout per component). All charts interactive via Plotly.
